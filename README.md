# Advertising Platform Demos

这里集中记录 GitHub Pages 上的各个 demo 地址，后续新增 demo 也统一补充到这里。

## Demo 地址

- SP 创建流程：https://sonia-cai.github.io/Advertising-platform/#/campaign
- SB 创建流程：https://sonia-cai.github.io/Advertising-platform/#/sb/campaign

## 新增 Demo 记录

新增 demo 时，请按下面格式补充：

```md
- Demo 名称：https://sonia-cai.github.io/Advertising-platform/#/对应路由
```

## 说明

- GitHub Pages 根地址：https://sonia-cai.github.io/Advertising-platform/
- 当前项目使用 hash 路由，`#/...` 后面的路径才是具体 demo 页面。
- 更新线上 demo 内容时，需要先执行 `npm run build`，再提交并推送生成后的 `docs/` 目录。
